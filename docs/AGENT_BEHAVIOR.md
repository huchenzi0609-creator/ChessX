# 棋子交谈、行动意识与吟游诗人输出

本实现调整依据2026-10-02首次真人试验反馈，以及用户随后提出的吟游诗人解除输出限制要求。规则基线仍为demo-v2.1，未增加移动奖励、强制出发、强制和解或导演调度。

## 交谈纪律

`prompts/piece-discipline.md`为新世界冻结的共用纪律。引擎同时注入版本化的`natural-dialogue-v1`行为协议，旧世界保留原人物／纪律快照，也能在后续未执行的请求中获得新的输出与行动提示。已提交的旧台词不被删改，已经选定的动作不被重新抽样。

- 100 token是台词上限，不能作为长度目标；内容少可以几个字回应，有新内容再说长些，没有新内容可以pass。
- 一次通常回应一个眼前的新点，不默认汇报目标、复述案情、重新宣告计划、要求别人自证或逐个逼问。语气随个性和情境改变，保留拒绝、急躁、隐瞒和锋利的可能性。
- `dialogue_recall`从本人已交付收件中选择近期实际听到的台词和最近三次本人发言，避免回合／结构事件把对话全挤出最近30条收件窗口。
- 普通对话的较长台词（去标点后至少20字符）若与最近本人台词完全相同，进入有界纠错；短应答及交涉中重复立场不受此门禁约束。换词复述、语气和话题循环由提示与人工复测评估，不用相似度阈值替角色决定该说什么。

## 内部引用不进入台词

`speech`中的“（参考233）”、编号脚注、内部receipt/event/message标记及已提供的完整来源ID，在事件提交前被拒绝。模型收到专门的自然语言重写反馈，至多按现有三次尝试协议纠错；不会静默删除引用、把失败文本交付给他人或把失败伪装成成功。

记忆整理的`source_receipt_ids`与故事的`event_refs`仍是合法结构字段；棋子不能把这些审计数据当作说话习惯。自然的“你刚才说……”、年份、门牌号仍可使用。规则能识别常见显式内部标记，不能机械证明所有隐晦元叙事和语义复述都已消除。

## 移动意识与信息边界

主行动／普通交谈上下文新增`navigation`：本人坐标、零基行列方向、休息状态、合法几何目标坐标列表、移动代价、会话与移动的关系。

目标列表只由棋盘边界、本人棋型、当前权限及本人局部观测计算；滑行棋子可选择未探索区域，但列表不承诺路径无人阻挡，不读取全局隐藏占位。兵的斜移仍要求邻近斜格有本人看得到的存活棋子；马仍只跳起点与终点。

`known_locations`仅包含当前视野人物和本人实际收到的位置回执。旧位置明确标为旧观测，不从全局状态更新成“实时定位”，不因知道人物名字而得到其坐标。普通会话不锁定移动，合法move会自动离开会话；语言阶段只能选择允许的leave／pass等行为，不能用“我去了”代替规则事件。

主行动提示提醒角色审视说过的打算与连续等待：寻找某人可以依据本人记得的报告、探索或改变计划，不必原地等所有人同意。休息／战斗锁定照常生效；系统不选目标、不强迫移动，也不保证每次出发都能遇到所找人物。

## 吟游诗人

移除原有固定2048 token成稿校验上限；故事段落不套用棋子100 token台词限制，也不注入棋子的交谈语气协议。故事可以按材料完整展开，不为了“解限”而填充无依据内容。

输出空间由剩余模型上下文与本段token预算动态分配；长输入按真实发送DTO（包括stage）分块，并为纠错反馈保留空间。旧任务的过大未完成块可以重新分割，已完成章节与来源范围保留。

章节能放入同一模型窗口时做整稿合成；超过单次窗口时把模型已写好且验证通过的章节按原顺序完整成稿，界面显示“分章成稿”和章节标题。正文及原始事件引用保持完整，不递归压缩或裁掉篇章来凑窗口。“继续编排”保留未完成job；只有已成稿后“重编本段”才开始新revision。故事请求不能覆盖未完成的模拟cursor。

API仍必须有有限的`max_tokens`，完整JSON、来源引用、公开推理1000 token上限、密钥隔离、调用／时间预算仍生效。单条来源事件或不可截断的人物资料超出物理容量、调用／时间预算不足时仍安全暂停，不把截断稿件当成完整故事。用户明确的新要求覆盖旧规范表中吟游诗人的固定正式输出上限，冻结规范文件保留作为历史基线。

本次核对[DeepSeek官方模型参数](https://api-docs.deepseek.com/quick_start/pricing/)确认`deepseek-flash`支持的输出容量高于当前本地16384上下文配置所能分配的空间；未自动提高本地上下文配置或运行预算，以保持调用成本控制。更长稿件可在核实服务能力后调整本地容量，但不是重新添加固定成稿上限。

新世界的`prompt_hash`覆盖分阶段系统提示；成功操作额外保存行为版本和提示manifest哈希，使旧存档续跑使用新协议的情况可审计。运行资料和真实样本只放在Git忽略的本地data目录。
