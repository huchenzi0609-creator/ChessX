# ChessX 设计决定清单（规则基线）

**用途**：记录自第二轮评审以来所有**已锁定**的设计决定，作为实现时的规则基线。
**状态标记**：✅ 已决定 ｜ ⚠️ 待定 ｜ 💡 由已定规则推导出的推论（不是新规则，但实现时需知道）
**最后更新**：2026-09-29

---

## 0. 系统定位（这条决定了其余一切怎么读）

> **这不是国际象棋，只是沿用了国际象棋的棋子移动规则。**
> 设定里没提到的规则不是"未定义"，而是"不存在"。
> 系统层面**无价值取向**：不给予角色奖赏或惩罚，只忠实执行先验规则。
> 真正的奖惩存在于角色内部，取决于它们的价值观。
> 一切先验结构的目的，是**增加叙事的可能性**，而不是限制它。

**由此推出的两条实现原则**：
- 规则层不写"什么重要"，只写"什么存在"。object 的价值、背叛的严重性、死亡的后果——全部由角色价值观决定。
- 初始状态（角色层）才是设计的重点。规则层越中性越好。

## 1. 棋子与棋盘

| 项 | 决定 |
|---|---|
| ✅ 棋子数量 | 最多 8 个，可任意设置，也可为空 |
| ✅ 棋子类型 | **只规定行进方式**，与人设/性格/目标完全无关 |
| ✅ 初始位置 | 可自定义 |
| ✅ 棋盘尺寸 | 8×8 ~ 64×64 可调（大尺寸为可选，非默认使用场景） |
| ✅ 公开信息 | JSON 文件（类型、颜色等） |
| ✅ 私人信息 | Markdown 文档（性格、公开目标、隐藏目标） |
| ✅ 量化指标 | **不设置数量化数值**。重大事件写入长期记忆文件，动机由文本决定 |

**💡 推论**：因为没有数值，"记忆是否准确"无法被系统机械校验。棋子可能说出没发生过的事——这在本文框架里不是缺陷（记错的角色本身是好故事），但需明确：世界状态的权威副本在**记忆层已经让位给文本**，只在地图层（位置、object 状态）保持代码权威。

## 2. 状态与回合循环

| 项 | 决定 |
|---|---|
| ✅ 循环 | **移动 → 休息 → 移动 → 休息……** |
| ✅ "思考" | **不再作为独立状态存在** |
| ✅ 休息回合数 | 由水平/垂直移动距离中的**较大者**决定（象 A1→E5 休 4 回合；车横穿 8×8 休 7 回合） |
| ✅ 马 | 休息回合数**固定为 3** |
| ✅ 轮空 | 移动回合可选择移动 0 格，**冷却 0 回合**，随时可再移动 |
| ✅ 静止态 | 棋盘上只有"休息中"和"轮空"两种不动的情况，均可被路径交涉命中 |

**💡 推论一（滑行子的速度账，已核算）**：滑行子平均推进速度 = d/(1+d)，**恒小于 1 格/回合**。也就是说它永远不比"每回合走一格"的棋子更快，最多追平（d=7 时 8 回合 vs 7 回合）。

→ 这不是缺陷，而是机制真正在做的事：**它把滑行子的优势从"速度"换成了"承诺能力"**。车可以宣布"我六回合后出现在那里"，对手必须围绕这个已宣布的威胁组织行动，而车在这六回合里什么都做不了。**叙事产出不是"谁快"，而是"谁敢"。**

**💡 推论二**：马固定休 3 回合 → 每 4 回合推进 3 格（约 0.75 格/回合），在 d≥4 时比滑行子更划算。马的节奏是"短促、可重复的小承诺"，车是"一次性的重注"。

## 3. 视野

| 项 | 决定 |
|---|---|
| ✅ 普通棋子 | 3×3（以自身为中心的 9 格） |
| ✅ 马 | 5×5 |
| ✅ 观测方式 | **主动注入**到提示词（不做工具调用，省一次 LLM 往返） |
| ✅ 其余信息 | 存放于上下文记忆 |

**💡 推论（盲目跳跃，用户已明确确认要这个效果）**：车在 A1 时视野只有相邻格，**看不见 E1 上有没有棋子**；但它跳过去时 E1 上的棋子确实在路径上，按规则要交涉。

→ **结果：车会和一颗它从未看见的棋子发生交涉。** 这是"拟人化不确定性"的直接体现，是设计意图，不是 bug。

**💡 覆盖率参考（供参考，不作为限制）**：8×8 上 3×3 视野覆盖 14%，期望 3.5 对棋子互相可见——遭遇足够频繁；64×64 上覆盖 0.22%，平均每 18 局才有一次相遇。大棋盘是"稀疏叙事"的可选档位。

## 4. 移动与路径

| 项 | 决定 |
|---|---|
| ✅ 通过语义 | **瞬时通过**（棋子只存在于落点，路径上不停留、不持续占据） |
| ✅ 路径阻挡 | 路径上有休息中/静止的棋子 → 进入交涉 |
| ✅ 多个阻挡 | **按路径方向依次交涉**：前一个放行则继续，不放行则**路径提前终止** |
| ✅ 目标点已有棋子 | **仍可选择放行**，效果为**两子同时占据同一格**（合法） |
| ✅ 同时到达空格 | 两个棋子进行一次**平等交涉**，可决定三种结果：**① 同时占坑　② 有一方让步　③ 谈崩则决斗** |

**💡 推论一（免费的叙事素材）**：因为交涉顺序由路径方向决定、与棋子强弱无关，**一颗兵拥有一票否决整条路径的权力，哪怕对方是后。**

**💡 推论二**：路径提前终止时，棋子停在**阻挡者的前一格**。

## 5. 交涉

| 项 | 决定 |
|---|---|
| ✅ 类别判定 | 移动发起前，按双方**能否互相攻击**判定 |
| ✅ 平等交涉 | 双方互能攻击 → 协商共同决定 |
| ✅ 优势交涉 | 单向能攻击 → **由能攻击的一方单方面决定** |
| ✅ 可能结果 | 让行（按原路径行进，无事发生）／截停（停在路径前一格，无事发生） |
| ✅ 谈崩 | 协商不成或一致同意 → **决斗** |
| ✅ 攻击的定义 | **攻击就是决斗**（不存在独立于决斗的吃子行为） |
| ✅ 同格棋子 | 被路径命中时**视作一个整体**，交涉规则与双人交涉相同 |
| ✅ 整体化原则的适用范围 | **仅在判定与规则层面适用**，用于统一逻辑；**不干涉对话内每个棋子分别说了什么、听到了什么、记住了什么** |
| ✅ 群体承诺归属 | 由上一行直接得出：**分开记录**。A 与 B 各自形成对 C 的印象，可以一个信、一个不信——由各自价值观决定 |
| ✅ 整体决斗 | **不存在"谁出战"的问题**：所有战斗（2 人 / 3 人 / N 人）走**同一条判定路径**，在场的都是参战者，没有代表制 |

**💡 推论（整体 ≠ 一个声音）**：既然整体化只管判定层，那么同格的 A、B 在交涉中可以**表达不同意见**——规则把它们视作一个交涉对象，不代表它们必须一致对外。这在博弈上是可被利用的（对手可以说服其中一个）。这仍然由角色层决定，不是规则问题。

**💡 推论（投票按个人算）**：踢人投票同理——群聊里每个成员都是独立投票主体，发起投票**不需要先取得"整体"同意**。

## 6. 对话

| 项 | 决定 |
|---|---|
| ✅ 邀请 | **不可拒绝**（被邀请方必须进入会话） |
| ✅ 退出 | 会话中任意一方**有权立即退出** |
| ✅ 解散 | 会话只剩一人时**自动解散** |
| ✅ 频率 | 一回合**仅能进行一次邀请** |
| ✅ 额度消耗 | 邀请被当场退出，**额度照样算用掉**（字面意思，无歧义） |
| ✅ 已在会话中的棋子被邀请 | **把该会话的成员视作一个整体**：C 邀请会话中的 B，视作 C 邀请"整个 AB 群体" |
| ✅ 踢人投票 | 任意成员可发起（**每人每会话最多一次**）；**除发起者与目标外的全体成员一致同意**则生效，否则对话继续 |
| ✅ 会话离席 | 是允许的动作 |

**💡 推论一（拒绝权的实质）**：因为"可以立即退出"，**"不得拒绝邀请"只保留了形式**——你仍会被拉进会话（浪费一个瞬间、留下一条公开记录），但不会被留住。

**💡 推论二（拒绝变成可见动作）**：邀请是公开的，退出也是公开的，所以**"被叫住然后转身就走"是一个会被所有在场者看到、并进入记忆的事件**。这是这套规则里拒绝的唯一成本来源：**不是系统的惩罚，是别的角色看见了。**

**💡 推论三（踢人投票的人数梯度，已核算）**：

| 会话人数 | 表决者 | 需要同意 | 后果 |
|---|---|---|---|
| 2 | 0 | — | 踢人投票**永久是空操作**（但可自由退出，不构成死锁） |
| 3 | 1 | 1 | **只需一人同意**——最容易踢人、最容易结盟 |
| 8 | 6 | 6 | 需全员一致——**大群聊极稳定、也极僵持** |

→ **三人会话是最脆弱的，八人会话是最僵硬的。** 这个梯度不是刻意设计的，但它自然产生，且是好的：**三人局里"我和谁结盟"变成一个真实的、有即时后果的决定。**

**⚠️ 已解决**：~~会话内部的回合节奏~~ → 见下列对话实现细则。

### 6.1 对话实现细则

| 项 | 决定 |
|---|---|
| ✅ 发言顺序 | **发起人先发言，之后所有人自由发言**（顺序固定 → 不需要 LLM 选下一个发言者） |
| ✅ CoT 上限 | 每句话 **≤1000 token** |
| ✅ 输出上限 | 每句话 **≤100 token**（强制短促来回，而非长篇独白） |
| ✅ 冷却 | 借鉴 ai-town：给单个 agent 的发言设置**短暂冷却**，避免一人喋喋不休 |
| ✅ 单会话总条数 | **≤50 条** |
| ✅ 成员认知 | 让 agent **知道这个上限存在**（预期管理，而非倒计时压力） |
| ✅ 回合内可见性 | 顺序发言，**后发言者自然可见先发言者的内容** |

**💡 推论一（50 条是按消息计，不是按回合计）**：

| 会话人数 | 每回合消耗 | 耗尽 50 条需要 |
|---|---|---|
| 2 人 | 2 条 | 25 回合 |
| 4 人 | 4 条 | 12 回合 |
| 8 人 | 8 条 | **约 6 回合** |

→ 与"一致同意才能加人"的规则配合：加人越难，大会话越罕见，这个梯度**自我平衡**。

**💡 推论二（50 条是节奏约束，不是成本约束）**：单条约 1.1k 输入 / 100 输出 token，50 条约 **55k 输入 + 5k 输出**——相对整个系统是很小的一块。

## 7. 决斗

| 项 | 决定 |
|---|---|
| ✅ 触发 | 交涉谈崩 |
| ✅ 判定方式 | 由**第三方战斗叙事 Agent**，注入**参战者的记忆**与**当前场上状态**，做**前向叙事推论**决定胜负 |
| ✅ 参战规模 | **2 人 / 3 人 / N 人走同一条判定路径**，无代表制；在场即参战 |
| ✅ 时长 | **最大回合数 max_round（默认 4）**。每进入下一回合，把内容重新注入参战棋子，由它们**选择是否认输**：认输则提前结束，不认输则继续，直到 max_round 强行结束交战状态 |
| ✅ 判定时点 | **逐回合推进**（因每回合需重新注入并收集认输决定） |
| ✅ 广播 | 交战状态广播到附近 **5×5** 范围 |
| ✅ 第三方 | 附近棋子**可加入并改变决斗结果** |
| ✅ 上下文代价 | 已核算：8 人混战第 4 回合约 7.9k token/人（记忆 6.4k + 叙事 1.2k），**随参战人数线性增长**，且认输机制让预期值远低于最坏值 |
| ✅ 打满收场 | 到达 max_round 时，**由叙事 Agent 根据已生成的结果认定胜者与败者**——与原固定回合机制相同，无需额外规则 |
| ✅ 认输语义 | 认输即提前结束战斗、进入胜负结算（与打满后的处理一致） |
| ✅ 决斗期间 | **不能移动**（位置锁定） |
| ⚠️ 待补 | 第三方加入败北的代价 |

**💡 设计要点一**：战斗状态**没有任何机械载体**（无 HP、无伤势字段、无位置变化），因此态势**只能从叙事文本里读出来**。叙事 Agent 每回合都要**重读自己前几回合写的内容**再决定下一步。
→ 这不是缺陷：它天然支持"他其实是装的"这类反转，因为"伤势"从来不是字段，只是叙事里的一句话。**战斗的真实状态是散文，不是数据结构。**

**💡 设计要点二**：战斗判定的输入必须是**每个参战者各自记得的版本**，而不是"客观事实汇总"。因为在这个系统里，**客观真相在记忆层本来就不存在**（只有地图层状态是代码权威）。
→ 各方记忆互相矛盾（A 记得是 B 先动手，B 记得是 A 先动手）**正是视角分化的体现，也是最该被叙事 Agent 利用的素材**，不应在输入前被"对齐"掉。

**设计立场（记录在案）**：本方案**有意放弃可复现性与可校准性**，理由是：
- 涌现出来的决定成败的细节太多，混合判定（先掷骰后写文）属于**回溯性构建**；
- 涌现叙事最好玩的地方在于**前向性**；
- 同一场决斗跑两次结果不同是**正常的、且是想要的**——历史上的事重演一遍本来就会不同。

## 8. 死亡与目标

| 项 | 决定 |
|---|---|
| ✅ 死亡来源 | 决斗（**攻击即决斗，不存在独立吃子**） |
| ✅ 墓碑 | 被杀棋子退出游戏，死亡处留下墓碑 |
| ✅ 墓碑性质 | 非实体，**不可交互、不阻挡路径**；发现者得知"该棋子已在此处死亡" |
| ✅ 墓碑不记录凶手 | 发现者只知道"该棋子已在此处死亡"，**不告知是谁杀的** |
| ✅ 目标更新 | 达成或失败后，根据过往记忆为自己指定新的长期目标 |
| ✅ 触发条件 | **由棋子 Agent 自己认定**："该目标已经达到"或"已经永远不可能达到"——判定权在角色层，不在系统 |
| ⚠️ 待补 | 身份锚点（哪些核心不可变）；防无限复仇链 |

## 9. object 对象

| 项 | 决定 |
|---|---|
| ✅ 描述 | 用 JSON 文档标示名称和说明 |
| ✅ 存在层面 | **实在层面，不在记忆层面**——agent 无法随意创生或毁灭 |
| ✅ 掉落态 | 可见，位于特定格子；棋子走到该格可"捡起" |
| ✅ 携带态 | 不可见，随携带者移动；携带者可丢弃到当前格，或交给视野内另一棋子 |
| ✅ 棋子死亡 | 携带的 object 原地转为掉落态 |

**💡 设计意义（这是本文档里最重要的一条）**：object 是**世界事实，不是奖惩机制**。规则不说"这个物件很重要"，只说"这个格子上有一个 object"。它是否重要、值不值得为它杀人——**全部由角色价值观决定**。

→ 同一枚权柄，在王眼里是合法性，在兵眼里是压迫的证据，在象眼里什么都不是。**系统对此保持沉默。**

→ 这也是对抗"收敛"的正确方式：**当规则本身不含价值取向时，"最优解"这个概念失效**——你没法算最优，因为你不知道对手在意什么。

---

## 10. 颜色与类型

| 项 | 决定 |
|---|---|
| ✅ 颜色 | 只是属性，标示身份（类似国籍），**不完全代表真实立场**；部分棋子有改变自身颜色的权限，但一般不会轻易更改 |
| ✅ 改色权限 | **在棋子 Agent 自己手里** |
| ✅ 颜色与攻击合法性 | **无关**：同色棋子本就可相互攻击。移动路径上的交涉**无论是否同色**都会触发（系统层面颜色不承担任何判定职责） |
| ✅ 类型 | 除系统规则特殊说明（如兵到底线升变），棋子**不具备改变类型的权限** |

---

## 11. 游戏结束时点

| 项 | 决定 |
|---|---|
| ✅ 无胜负 | 游戏**没有绝对的胜负，不存在游戏结束条件** |
| ✅ 回合限制 | 由使用者决定跑多少回合；结束后由**"吟游诗人" Agent** 编排这几回合的叙事 |
| ✅ 续跑 | 回合结束后，使用者可指定再跑若干回合 |
| 💡 建议 | 吟游诗人的输出**应能指回事件账本中的具体事件**（提到的每个事件都能在账本中找到）。否则它自由发挥会编造未发生的事，而系统无从察觉 |

## 12. 待定项汇总（按优先级）

| # | 待定项 | 优先级 | 影响 |
|---|---|---|---|
| 1 | **身份锚点**（哪些核心不可变）+ 防无限复仇链 | 中 | 防目标链无限生长（§8） |
| 2 | 第三方加入决斗败北的代价 | 低 | 防"加入永远是纯收益"（§7） |

**另有两条属于设计建议（非规则待定）**：
- **吟游诗人是否必须引用账本**（§11）：若不要求，它会编造未发生的事，而系统无从察觉。

**✅ 规则联动（记录在案，这是设计意图而非问题）**：
**墓碑不记录凶手** + **目标更新的触发条件是"永远不可能达到"** → **不构成阻断，而是把目标推向调查阶段**。

- 棋子发现墓碑后知道"有人死在这里"，不知道是谁杀的 → 这属于**当前缺少信息**，**不属于"永远不可能达到"**，因此**不会触发目标更换**。
- 目标不是消失，而是**换成一个更前置的形态**：`为皇后复仇` → `查明谁杀了皇后` → `复仇`。找凶手本身就是可执行的目标，需要与其他棋子互动（打听、试探、结盟、逼问）。
- **这是叙事的发生器，不是缺陷**：信息缺口把角色从"执行一个动作"推向"开始一段调查"，**故事从缺口里长出来，而不是从答案里长出来。**
- 系统中天然存在的不对称：**杀了人的棋子自己知道，别人不知道** → 有隐瞒、有紧张、有暴露。
- 墓碑只提供地点，所以调查的可行路径是**回溯**：死者最后出现在哪、谁在附近、谁目击了。这也意味着**安排一个目击者是让复仇线成立的最自然方式**。

**⚠️ 边界情况（供参考，非待定）**：严格说，"永远不可能达到"**无法被确证**——即使找不到线索，也可能只是还没找到。现实中的人（和角色）靠**放弃**来终止这件事。所以这个触发条件的判定权必须在棋子自己手里（你已经这样定了），否则会陷入无限调查。若某个棋子永不放弃，这是角色性格的体现，不是系统故障。

**已解决（不再待定）**：
- ~~整体决斗由谁出战~~ → **不适用**：所有战斗同一条判定路径，无代表制
- ~~群体承诺归属~~ → **分开记录**：整体化原则仅在判定层适用，不干涉对话内容
- ~~战斗判定的时点~~ → **逐回合推进**（每回合重新注入 + 收集认输决定）
- ~~参战规模上界~~ → **认输机制**让时长成为角色决定，成本随人数线性增长且预期值远低于最坏值
- ~~会话内部的回合节奏~~ → **发起人先发言，之后自由发言**（顺序固定，无需 LLM 选发言者）
- ~~max_round 到达后如何收场~~ → **由叙事 Agent 认定胜负**，与原固定回合机制相同
- ~~对话单条消息如何产生~~ → **顺序发言，后者自然可见前者内容**
- ~~同时到达空格~~ → **两子进行一次平等交涉**，可决定：同时占坑 / 一方让步 / 决斗
- ~~目标更新的触发条件~~ → **由棋子 Agent 自己认定**"已达到"或"永远不可能达到"
- ~~改色权限~~ → **在棋子 Agent 自己手里**
- ~~颜色是否影响攻击合法性~~ → **无关**，同色本就可互攻
- ~~决斗期间能否移动~~ → **不能移动**
- ~~墓碑是否记录凶手~~ → **不记录**

**说明（避免把"实现未定"误记为"规则未定"）**：以下两项已能从已有原则推出，属实现时的选择，不需单独决定——
- **"重新注入的内容"**：由"叙事 agent 需知道前情"推出，包含本场已生成叙事 + 该棋子记忆与状态；
- **"认输"的语义**：按"认输则提前结束"的措辞，即结束战斗进入胜负结算，与打满后的处理一致。

## 13. 唯一仍存在的设计风险（非规则问题）

**收敛**：这套规则没有任何机制阻止冲突往和平收敛——谈成就无事发生，无事的回合多了就没有故事。按本设计的原则，**这不该用规则解决**（那会变成"为了情节设计结构"）。

**它只能靠初始角色层解决**：你设计的初始角色之间，**价值观必须真的互相冲突**。如果八个棋子的价值观恰好都偏向"协商优先"，就不会有故事。

**轮空规则让这一点更重要**：棋子可以选择永远不动、永远不参与。理论上一个棋子可以无限轮空。**这不是系统问题，但意味着初始人设必须让角色"想做点什么"。**
