# 架构与开发责任

## 分层

| 目录 | 职责 | 禁止依赖／越权 |
|---|---|---|
| domain | 场景、Intent、规则档、初态、RuleError | 不调用网络或存储 |
| rules | 纯几何、局部视野、合法状态操作、不变量 | 不评判角色价值观，不替模型裁决胜负 |
| contexts | 按角色构造观察／输入，事件字段投影、预算 | 不读其他人的资料来补该角色的记忆 |
| llm | 单次服务请求、显式CoT／schema／token校验 | 不改世界、不自动无CoT降级、不回显密钥 |
| runtime | 单写入执行器、持久阶段、移动／会话／战斗子协议 | 模型等待不占数据库事务，不把错误当角色决定 |
| storage | SQLite、事件、逐提交检查点、操作／命令／文本版本 | 浏览器／模型不直接写表 |
| api | 本机命令、投影、补发、回放与导出 | 不输出配置密钥；校验错误不回显请求内容 |
| frontend | React观察台与用户命令 | 不是世界真源，不接收或保存API key |

## 持久状态机

世界按START→PRIMARY→COMBAT→ORDINARY→MEMORY→END→BARD推进。
各模块每步最多一次模型响应；等待者的work、成员、票、路径占用快照、消息计数都在cursor／世界中。
一份数据库事务保存状态、事件、接收者当时的字段投影、下一cursor以及成功操作结果。
每次提交保存完整checkpoint用于精确恢复／回放。最多八角色的首版优先可审计性；大量长局时应
将全量快照改为稀疏checkpoint＋状态补丁，以控制磁盘增长，不能剪掉原始已发生历史。

模型操作槽由turn／stage／协议ID／许可索引组成；attempt独立编号。控制暂停递增generation、
取消在途请求，回调提交前再核对generation和seq。进程重启只恢复为暂停，不自动消费API额度。
旧pending请求标obsolete；同一slot已提交的事实由cursor避免重做。提供方端执行次数不可保证exactly-once。

## 语言与结构

普通、通行、同格和战后协议共用消息身份、字段白名单、最大50句与有界许可原则；
各协议kind分别持有结束判定：普通关闭、通行结算／开战、战后终止全体胜者选择。
实现分成DialogueMixin／MovementMixin／CombatMixin，统一由WorldRunner执行和Store提交。
未来可将重复的许可／计数进一步抽成小型ConversationEngine，不要把三个结构结论混成同一个枚举。

战斗无HP／伤势数值，叙事Agent分别读取参战者记忆；向角色发送public_narrative，不发送叙事者CoT。
胜败集合必须完整、互斥且均非空；认输者必须败。死亡只能由结算授权操作产生。
释放必须所有胜者明确同意；失败的释放表决不等于自动死亡。不同败者的投票状态独立。

## 信息边界

默认不知道全员名册；本人Markdown定义开局已知人物。局部可见结构在决策前直接注入。
每条事件在提交时生成按接收者的receipt，不在事后按新位置追溯传播。
本人记忆可以误认，事件日志只能说明谁说过什么。初始人格只读，目标／记忆存版本。
未公开记录不能进吟游诗人事件版；引用ID存在不证明文本语义完全正确。

浏览器角色视角读取独立perspectiveDTO；全知观察台／研究inspection不得复用为角色prompt。
公开CoT是提供方返回的推理文本，只存本地私密操作记录，普通字幕、角色收件箱和成稿不读取。

## 本地安全

.env.local权限0600；数据库及WAL／SHM在私有data目录。所有服务仅监听loopback，Origin与Host受控，
API密钥只用于配置模型服务的Authorization头；对方回显密钥的成功响应也在保存前拒绝。
请求校验、HTTP错误和运行失败均提供代码，不返回原始请求／上游内容。普通导出不含私人档案／CoT；
研究导出是本机研究者显式操作，不会自动发送到外部。公开部署需要另做身份认证与多用户授权。

单进程约束由数据库同名锁文件的POSIX进程锁强制执行（当前支持macOS／Linux）；第二后端进程
不能拥有同一库。初始seq=0快照与WorldCreated以后的逐提交快照均可回放，并校验SHA-256。
分段故事可分块生成；事件区间冻结，重编保留revision，不推进世界回合。尚未完成的旧段故事
在续跑时先完成，再建立新段，不丢掉请求或把未来事件混进旧故事。


## 0.2.0 人物与文件预设

新增 presets 库只负责本地结构化文件：公开系统JSON＋私人Markdown原子对、预设间引用和CAS版本。
API作者操作与角色输入明确分开；创建世界时解析引用并复制文档，运行器不动态读取变动的作者文件。
共用纪律冻结到世界，作为系统消息；私人设计只在本人user资料通道出现，初始化私人目标及初始记忆。
“公开目标”不是观察字段。目录权限、严格ID、符号链接／路径边界、版本冲突和同ID创建保护由库控制。
详情见 CHARACTER_AUTHORING.md。
