# ChessX 观测台

React + TypeScript + Vite 本地前端。后端运行方式见仓库根 README。

```sh
pnpm install
pnpm dev
```

开发服务绑定 `127.0.0.1:5180`，`/api` 代理至 `127.0.0.1:8001`。

```sh
pnpm build
pnpm test
pnpm format:check
```

- `lib/api.ts` 负责 HTTP 契约与下载；密钥从不进入前端配置。
- `hooks/useWorld.ts` 负责快照、分页账本补发与断线后重新连接。角色视角仅请求角色投影，不请求全知快照或全局账本。
- `components/` 负责棋盘、场景配置、事实记录、故事与授权研究检查。提供方推理默认折叠，仅在研究视角主动展开后加载。
- `App.tsx` 组合视角、运行控制与实验导航。历史回放禁用写操作；角色视角隐藏全局会话、战斗、故事与导出。

工程固定响应明确标记“非 AI”。真实模型模式须由服务端配置并通过模型能力校验；HTTP 成功不代表真实叙事质量通过验收。

测试覆盖角色数据隔离、雾区可访问名称、研究记录延迟加载、无效场景阻断、账本补发去重及故事原始事件导航。工程样例与真实模型实验分开验收。
